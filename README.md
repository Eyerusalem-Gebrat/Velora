# Velora — E-Commerce Mobile App

## Description

Velora is a Flutter e-commerce app built on the [Fake Store API](https://fakestoreapi.com). Users can log in, browse and search products, view product details, manage a cart, and view their profile with the session and cart saved locally so they persist across app restarts.

## Problem It Solves

Provides a complete, realistic shopping flow on a live API, including proper state management, local persistence, and handling of loading, empty, and error states.

## Main Features

- User login with a session that persists across app restarts
- Product browsing with category filters and title search
- Shopping cart with quantity controls, saved locally
- User profile pulled live from the API
